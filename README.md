# 👑 CK3: 전생한 악당들 (Reincarnated Villains 867)

Crusader Kings III (867년 북마크) 근현대 인물 전생 블랙코미디 시나리오 모드 스위트입니다.

## 📦 포함 모드 패키지 (`custom-mods/`)
1. **본편 (`reincarnated-villains-867`)**: 서방편(7인) · 동방편(4인) 북마크, 10개 고유 문화·전통·무장병, 11개 고유 이념 신앙, 전용 결단 및 풍자 유물
2. **CFP 호환 패치 (`reincarnated-villains-867-cfp-compatch`)**: Community Flavor Pack (`2220098919`) 유전자·이발소 호환 패치
3. **V3 의상 크로스 패치 (`reincarnated-villains-867-v3-compatch`)**: Victoria3 Crossgame Portriat (`3836483821`) 의상 연동 + 2,311키 전체 한국어 번역 + 커스텀 3D 완장·훈장·군모

## 🛠️ 주요 명령어
- `npm run sync:mod`: 로컬 CK3 모드 폴더 및 런처 플레이셋 자동 동기화 (UTF-8 BOM + CRLF 정규화 포함)
- `npm test`: 전체 Clausewitz 구문 · 인코딩 · 로컬라이제이션 대칭 · 3D 메쉬/DDS 무결성 회귀 테스트 실행
